# LayerLens

[LayerLens](https://layerlens.techjeeper.com/) — a batch 3D model photo optimizer for Printables, MakerWorld, Thangs, Snapmaker Spaces, and Cults3D.

Source: [TechJeeper/LayerLens](https://github.com/TechJeeper/LayerLens)

## Features

- Multi-image batches with per-image crop memory and roles (hero / gallery / detail)
- Project name used for ZIP and export filenames
- Brand kits, logo watermark, safe-margin guides
- Color/lighting (exposure, contrast, temperature, vignette)
- Subject auto-focus, listing checklist, Cults size estimate, Snapmaker OCR
- Paste / drag-drop, project save-load (localStorage + JSON)
- One-click links to each marketplace upload page

## Run locally

```bash
python3 -m http.server 43127
```

Open [http://127.0.0.1:43127](http://127.0.0.1:43127).

## Clone on Windows

```powershell
git clone https://github.com/TechJeeper/LayerLens.git C:\Project\LayerLens
```
