# LayerLens

Local copy of [TechJeeper/LayerLens](https://github.com/TechJeeper/LayerLens) — a 3D model photo optimizer for Printables, MakerWorld, Thangs, Snapmaker Spaces, and Cults3D (max 8000×8000, 10 MB).

## Run locally

```bash
# from this directory
python3 -m http.server 43127
```

Then open [http://127.0.0.1:43127](http://127.0.0.1:43127).

## Clone on Windows

```powershell
git clone https://github.com/TechJeeper/LayerLens.git C:\Project\LayerLens
```
